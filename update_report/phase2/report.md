## 4. สิ่งที่ต้องทำใน Phase 2 (ยังไม่เริ่ม)

- Pre-processing: encode `gender` และ `smoking_history`, train/test split แบบ stratified
- จัดการ class imbalance (ข้อมูลจริง: ไม่เป็น 91.5% / เป็น 8.5%)
- สร้าง baseline (Logistic Regression) แล้วเทียบโมเดลอื่น
- ทดลองทั้งแบบมีและไม่มี `HbA1c_level` / `blood_glucose_level`
- ประเมินด้วย recall, F1, AUC
