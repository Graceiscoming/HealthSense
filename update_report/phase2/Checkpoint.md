# Checkpoint โครงงาน

## ชื่อหัวข้อโครงงาน

HealthSense: Predicting Chronic Disease Risk from Daily Lifestyle

## สมาชิก

1. นายวัชรพงศ์ มาลัง รหัส 67102010174
2. นาย นราธิป สุวณิชย์ รหัส 67102010517

## ระบุปัญหาที่ต้องการแก้ไขด้วยข้อมูล

โรคเรื้อรัง เช่น เบาหวาน ความดันสูง โรคหัวใจ เป็นสาเหตุการเสียชีวิตอันดับต้น ๆ และหลายโรคป้องกันได้ถ้าปรับพฤติกรรม แต่คนส่วนใหญ่มักไม่รู้ตัวจนกว่าจะป่วยแล้ว

โครงงานนี้จึงอยากทำนายว่าแต่ละคนมีโอกาสเป็นโรคเบาหวานหรือไม่ จากข้อมูลพื้นฐาน ประวัติสุขภาพ การสูบบุหรี่ และค่าตรวจสุขภาพ เพื่อให้รู้ตัวและปรับพฤติกรรมได้ก่อนป่วยจริง

## ใครได้ประโยชน์ ถ้าโมเดลทำนายได้ดีจะนำไปใช้ตัดสินใจเรื่องอะไร

| ผู้ได้ประโยชน์ | นำไปตัดสินใจเรื่อง |
|---|---|
| ประชาชนทั่วไป | ประเมินความเสี่ยงของตัวเอง แล้วตัดสินใจปรับพฤติกรรมหรือไปตรวจก่อนป่วย |
| หน่วยงานสาธารณสุข | คัดกรองกลุ่มเสี่ยงสูง และเลือกพื้นที่/กลุ่มที่จะส่งทีมไปตรวจเชิงรุก |
| บริษัทประกันสุขภาพ | ประเมินความเสี่ยงของลูกค้า และออกแบบโปรแกรมส่งเสริมสุขภาพ |

ถ้าโมเดลใช้ได้ดี จะช่วยให้ตรวจพบผู้ป่วยได้เร็วขึ้น และมีคนเข้ารับการตรวจคัดกรองก่อนมีอาการมากขึ้น

## ต้องใช้ ML จริงไหม?

คิดว่าควรใช้ เพราะ

- ความเสี่ยงเบาหวานมาจากหลายปัจจัยพร้อมกัน เช่น อายุ BMI ความดัน โรคหัวใจ และค่าน้ำตาล จากกราฟ correlation ไม่มีตัวแปรไหนที่สัมพันธ์กับ diabetes เกิน 0.42 จึงใช้เกณฑ์ตัวเดียวแยกกลุ่มให้ชัดไม่ได้
- ข้อมูลมีมากพอ (96,146 แถวหลังทำความสะอาด)
- อยากได้ผลเป็นระดับความเสี่ยงของแต่ละคน เพื่อนำไปจัดลำดับกลุ่มเสี่ยง

แต่มีข้อสังเกตว่า HbA1c_level และ blood_glucose_level เป็นค่าที่แพทย์ใช้วินิจฉัยเบาหวานอยู่แล้ว ถ้าใช้กฎง่าย ๆ เช่น HbA1c ตั้งแต่ 6.5 ขึ้นไป อาจได้ผลดีพอสมควรอยู่แล้ว ใน Phase 2 จึงจะสร้างโมเดลพื้นฐาน (เช่น Logistic Regression) มาเทียบก่อน และลองทั้งแบบที่ใช้และไม่ใช้สองค่านี้ เพราะเป้าหมายคือทำนายก่อนมีอาการ

## คำอธิบายเกี่ยวกับชุดข้อมูล

### แหล่งที่มา

Kaggle: Diabetes Prediction Dataset

### ชุดข้อมูลนี้เกี่ยวกับอะไร มีจำนวนข้อมูลเท่าไร

ชุดข้อมูลนี้เป็นข้อมูลทางการแพทย์และประชากรของผู้ป่วย ใช้ดูว่าแต่ละคนเป็นเบาหวานหรือไม่ มีข้อมูลเพศ อายุ ประวัติความดันสูงและโรคหัวใจ ประวัติการสูบบุหรี่ และค่าตรวจ (BMI, HbA1c, ระดับน้ำตาลในเลือด)

มีทั้งหมด 100,000 แถว 9 คอลัมน์ (1 แถวคือผู้ป่วย 1 คน) หลังลบแถวซ้ำ 3,854 แถว เหลือ 96,146 แถว

## ระบุ feature และ target

Feature มี 8 ตัว

| Feature | ความหมาย | ชนิด |
|---|---|---|
| gender | เพศ (Male/Female/Other) | Categorical |
| age | อายุ (0-80 ปี) | Numeric |
| hypertension | เป็นความดันสูงหรือไม่ | Binary |
| heart_disease | เป็นโรคหัวใจหรือไม่ | Binary |
| smoking_history | ประวัติการสูบบุหรี่ | Categorical |
| bmi | ดัชนีมวลกาย | Numeric |
| HbA1c_level | น้ำตาลสะสม 2-3 เดือน | Numeric |
| blood_glucose_level | น้ำตาลในเลือดขณะตรวจ | Numeric |

Target คือ diabetes (1 = เป็นเบาหวาน, 0 = ไม่เป็น)

## ระบุ type of learning / task

เป็น Supervised Learning เพราะมี label คือ diabetes และเป็นงาน Classification แบบ 2 คลาส (เป็น / ไม่เป็นเบาหวาน)

ข้อมูลไม่สมดุล คนส่วนใหญ่ไม่เป็นเบาหวาน จึงต้องจัดการเรื่อง class imbalance และดู recall, F1, AUC ประกอบ ไม่ดูแค่ accuracy
